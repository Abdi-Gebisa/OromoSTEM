OROMIA STEM SUITE — UPDATED ENHANCEMENTS

Included: oss-enhancements.js

This version preserves the existing physics laboratory simulations, calculations,
graphs, experiment report, language selector, accessibility controls, and worksheet.
It simplifies Teacher and Impact, replaces the generic footer with a personal
creator statement and 2026 copyright, and fixes opening a laboratory detail view.

INSTALL:
1. Open your Oromia STEM Suite GitHub repository.
2. Open the existing file named oss-enhancements.js.
3. Replace its entire contents with this file's contents.
4. Commit the changes.
5. Refresh the website. If the old version remains, refresh again after a minute.

Keep the filename exactly oss-enhancements.js because index.html may reference it.
This file expects the page to already contain the main site and its existing styles.
